# VidForge Custom Update, 2026-10-20

The Docker release is `2026.10.20`; the application's health version is
`2026.10.19.7`. The stock base is pinned to
`afflicted9436/tayzu31t3@sha256:4f04340ebbd95a7b45958f05f32246e13e25ee3d04f433a0f555d1de331599b2`.
Build from that stock base plus this overlay. Do not use an older custom image
as the upstream base.

The new native Packaging pipeline mines and scores script moments, pairs titles
with thumbnail text, and runs a cold-viewer clarity check. Our named-person
policy retains the real subject while preserving the new moment schema and
the distinct compositions of non-reference variants. Native multilingual speech
tokenization is preserved byte-for-byte.

Five custom interventions are retired because reviewed native code supplies them:

- Segment `wordSyncVersion` persistence.
- B-roll final checkpoint compatibility for verification and slow windows.
- Stable B-roll/composite-video input hashes without mutable status fields.
- Empty working-directory age protection in both storage backends.
- The extra FX output marker, made unnecessary by that native protection.

`native-retirements.json` pins the reviewed replacement functions and storage
sources. The two FX rows in `/custom` are read-only native protections; legacy
saved flags remain readable without changing the saved settings. The current
40-hook contract is `vf-custom-40-20261020`; it requires
`fflow.nativeFxDirectoryProtection` instead of the retired sentinel injection.
Unknown source changes still fail the build.

Home CPU/NVENC, scene analysis, maps, Motion dispatch and FIFO-preserving native
recovery are retained. Native callbacks, renderer boundaries, frame-rate and
codec contracts are requalified against this release. Scene previews also honor
the new native inline-thumbnail option. Do not weaken the RAM gate, licensing,
deadlines or counted server fallback to accept an update.

Build and independently verify the immutable resulting image ID:

```sh
docker build --pull=false --network=none -t local/vidforge-custom:20261020-74-packaging .
python3 update-tools/verify_image.py local/vidforge-custom:20261020-74-packaging \
  --expected-version 2026.10.19.7 --docker-context default
```

Run the overlay regressions and an isolated cold start before a controlled
service-only deployment. Preserve the database/media volumes, credentials and
settings. Keep a private rollback image including hot source plus an online
SQLite backup. A code rollback must not overwrite newer job progress with an
older database. Home workers and tunnels remain deployment-specific companions.
